# Action Template Lab

قالب أكشن للجوال داخل المستودع `hsnsn`.

## Android APK
تم تحويل المشروع إلى تطبيق Android بسيط يعتمد على WebView ويحمّل واجهة القالب محليًا من داخل التطبيق. يوجد GitHub Actions workflow يبني نسخة Debug APK تلقائيًا عند أي تحديث على فرع `main`.

## الاستخدام
1. افتح التطبيق على الجوال.
2. أضف فيديو من الجهاز.
3. حدد وقت البداية والنهاية.
4. اختر مؤثر الأكشن: Combo / Shake / Zoom Punch / Flash / Whip / Glitch / Motion Blur / Stutter.
5. عدّل قوة المؤثر وتكرار الضربات.
6. اضغط «معاينة الجزء» للتأكد من النتيجة.
7. اضغط «تصدير الفيديو» ثم «تحميل النتيجة».

## ملاحظات
- تغيير المؤثر لا يغيّر الفيديو الأصلي؛ فقط غيّر المؤثر وصدّر من جديد.
- التصدير الحالي WebM داخل المحرر.
- الإصدار الحالي v1 ويمكن تطويره لاحقًا إلى MP4، مزامنة BPM، مسارات متعددة، وانتقالات بين عدة مقاطع.
